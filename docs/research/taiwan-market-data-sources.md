# 台灣市場資料來源與授權盤點

> **2026-08-15 product decision:** ADR 0017 排除本文建議的付費歷史檔、主動派送與另購新聞；正式產品只使用逐一明示 OGDL 的 distributions 及自首次取得日起的 observed archive。本文的來源事實仍供研究，付費選項不再是 requirement 或 fallback；更新後工程政策見 `official-zero-cost-market-data-policy.md`。

查證日期：2026-08-13

## 結論

生產導向 MVP 可以先用政府資料開放平臺列明採「政府資料開放授權條款第 1 版」（OGDL 1.0）的 TWSE、TPEx、MOPS 摘要、TDCC、TAIFEX、主計總處、中央銀行與國發會資料。OGDL 1.0 明確允許不限目的、時間及地域，免授權金重製、散布、公開傳輸、編輯、改作及再授權，但每份資料及衍生物都必須依規定顯名；未顯名會被視為自始未取得授權。這使資料快照、七年保存、內部建模及衍生特徵可行。[政府資料開放授權條款第 1 版](https://data.gov.tw/license)

但「公開可查」不等於「可由爬蟲自動擷取」。TWSE 與 TPEx 的一般網站條款都禁止未經同意以自動程式、蜘蛛、爬蟲或擷取程式下載資料；只有交易所同意的方式，或經政府資料開放平臺授權的資料集例外。因此正式連接器只能使用官方 OpenAPI／開放檔案端點、資訊商店的契約化下載介面或另行取得書面同意，不能把互動查詢頁的未文件化端點當成 API。[TWSE 使用條款](https://www.twse.com.tw/zh/terms/use.html)；[TPEx 網站使用條款](https://www.tpex.org.tw/zh-tw/gtsm_disclaimer.html?l=zh-tw)

七年、時間點正確的行情與完整公告／財報也不能只靠當前 OpenAPI 快照。建議以交易所付費歷史檔回填後，把每日 OGDL 或契約 feed 存成不可變快照；MOPS 完整即時資料用主動派送服務，新聞全文用另購授權服務。授權尚未寫明的任何來源一律停用，不作「既然公開就可以保存」的推定。

## 共通授權規則

- 對每一個 OGDL 資料快照保存 `publisher`、資料集名稱與版本、取得網址、取得時間、授權版本及內容雜湊；對外展示時依 OGDL 附件顯名。
- OGDL 只涵蓋資料提供機關有完整著作財產權或有權再授權的開放資料，不涵蓋商標、專利，也不免除個資及第三人著作人格權義務。[OGDL 定義、授權範圍與義務](https://data.gov.tw/license)
- 下表「可保存」只表示來源文件已支持保存／重製；「不可」或「待確認」不得由工程端自行放寬。
- 「速率限制未公告」不是無限制。先採每主機單執行緒、條件式請求、指數退避與快取；若服務回應 `429`、`403` 或要求降載，立即停止並向來源擁有者確認。
- 交易所與資訊商店條款會變更。資料來源登錄表應記錄條款雜湊，部署前及至少每季重新查驗。

## MVP 建議組合

1. **零憑證基線**：TWSE、TPEx、MOPS、TDCC、TAIFEX 的 OGDL OpenAPI／CSV，加上主計總處、中央銀行與國發會；只從上線日起每日保存資料快照。
2. **七年回測必需採購**：TWSE 每日收盤行情及三大法人歷史；TPEx 正式盤後／歷史檔；必要時 MOPS XBRL／主動派送歷史回填。沒有簽妥保存權，不將付費原檔寫入七年資料湖。
3. **新聞模態**：先用 MOPS 重大訊息與公司公告；CNA 或其他新聞供應商由部署者自備憑證。未簽新聞授權時，模型必須能在新聞模態缺失下推論並標示缺失來源。
4. **歷史時間點**：所有來源都保存 `event_time`、`published_at`、`first_observed_at`、`retrieved_at`、資料版本／內容雜湊；修訂版不可覆寫。國發會等回溯修正資料尤其要以 vintage 方式入庫。
5. **對外展示**：優先顯示衍生特徵、機率、影響因素及來源連結。原始行情、專有指數成分、新聞全文與付費檔案只有在契約明確授權時才顯示。

## 上線前法務／採購閘門

- 取得 TWSE、TPEx OpenAPI 的書面呼叫政策或官方聯絡回覆，確認配額、批量回填、服務終止與資料更正處理。
- 對交易資訊商店逐項取得完整契約，確認內部／外部使用定義、七年留存、終止後保存、災備、模型訓練與衍生輸出權；商品頁價格只作預算估計，以下單時報價為準。
- 確認使用「臺灣 50／中型 100」名稱、當期及歷史成分股作預設股票池是否需要 TIP／FTSE 授權。
- 簽新聞授權前不要下載或保存 CNA／其他新聞全文；要求授權明列 NLP、嵌入、訓練、推論、標題／摘要展示與撤稿處理。
- 建立資料集級顯名模板與授權稽核測試；若資料未附明確授權版本或來源擁有者無權再授權，連接器預設 `disabled`。

## 未採用的捷徑

- 不使用 Yahoo Finance、未登錄第三方聚合網站或社群套件作正式台股歷史來源：它們不是本票券允許的一手來源，且授權與公司行動口徑未在此證實。ADR 0018 後續將 FinMind 免費 API 登錄為例外的正式資格候選；這只允許它接受同一套完整資格審查，並不使它在權利、歷史、修訂、日曆、公司行動或 listing lifecycle 證據通過前成為正式合格來源。
- 不逆向 MOPS、TWSE 或 TPEx 網站內部端點；OpenAPI 未涵蓋的資料改走官方資訊商店、主動派送或書面同意。
- 不以 `robots.txt` 允許作著作權或再散布授權，也不以沒有公開速率限制推定可以高頻呼叫。
