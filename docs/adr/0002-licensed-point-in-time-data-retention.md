# 授權來源與七年時間點證據鏈

系統只從官方介面、公告、申報資料、授權 feed，或明確允許自動存取的頁面取得資料；付費來源使用部署者提供的憑證，禁止繞過存取控制。正式模型輸入必須獲准保存原始、正規化及必要衍生證據直到所有正式相依產出的七年期限結束；不允許七年保存或模型用途的內容降為摘要、metadata、研究隔離或停用，不能為滿足復現目標而擴張來源權利。

來源政策、契約或合法處置要求較短保存或刪除時，政策性刪除優先於一般七年保存目標：受影響資料及衍生模型沿譜系停止使用並刪除，只保留政策允許且不含被禁止內容的 tombstone、影響評估與刪除證明。這以降低可用來源範圍及增加授權採購成本，換取可證明的時間點復現與來源權利遵循。
