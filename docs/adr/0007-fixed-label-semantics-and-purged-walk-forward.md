# 固定標籤語意與保守隔離的滾動回測

> 自 P2 起，固定七年訓練長度由 ADR 0017 取代；固定標籤、realized-session 端點、purge、embargo、once-only test 與禁止隨機切分仍有效。

系統採固定、版本化的波動度感知三分類標籤，並以 realized exchange sessions 建立 7 年訓練、1 年校準／驗證、20-session 標籤清除區、20-session 測試隔離期及 1 季測試的 walk-forward 回測摺。這犧牲部分可訓練樣本並保留長區間市場偏斜，換取跨市場一致的經濟語意、對公司行動與休市的正確處理，以及模型選擇不接觸未來標籤或測試結果的可稽核保證；不採隨機切分、測試期分位數重標或缺價端點順延。
