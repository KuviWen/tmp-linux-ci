# 以台美雙市場垂直 tracer bullets 分期交付

> **2026-08-15 supersession:** ADR 0017 保留雙市場垂直 tracer-bullet 方法，但取代本文的固定 600＋1,400 擴張門檻；後續只擴張到官方零成本來源與本機資源實際可驗證的支援池。

系統先以台灣與美國各一條穿過來源 adapter、時間點證據、資料集與特徵、預測、權威帳本、REST／研究介面及營運證據的垂直 tracer bullet 建立工程脊柱，再依 1＋1、10＋10與官方零成本來源／本機量測實際可支援的股票池逐步擴張；不先建資料、模型、介面或監控等彼此等待的水平平台。這以每階段較小但可端到端驗收的範圍，換取較早暴露來源權利、市場差異、時間點、服務指派及部分故障風險，並避免沒有第二個 adapter 的假 seam 與空 module；分期與trace IDs由[交接契約](../design/phased-architecture-and-spec-handoff.md)固定。
