# 研究介面資訊架構

> **2026-08-15 product boundary:** ADR 0017、0018 與主 spec 的 `COST-0-01` 取代本文對固定 100＋100／2,000 listing、商業新聞／consensus 與外部 production service 的必要假設；研究介面顯示實際合格零付費支援池，並把缺少憑證或不支援來源明確呈現為 `credential_required`／unavailable／excluded。本文的可追溯性、繁中、URL state 與 accessibility 契約仍有效。

## 狀態

第 10 號介面原型驗證後的正式設計契約。原型只作一次性設計證據，正式實作不得直接複製原型程式；1＋1最小介面到100＋100完整研究MVP的分期驗收由[分階段架構交接契約](phased-architecture-and-spec-handoff.md)固定。

## 決策摘要

首版採兩層研究路徑：

1. **比較矩陣**是研究入口，以股票池內的掛牌為列，同時顯示 1／5／20 個交易日的三分類機率、信心分數與資料支援狀態。
2. **標的研究頁**是單一掛牌的深入視圖，並列預測、主要影響因素、來源證據、歷史預測、滾動回測及完整版本譜系。

「證據卷宗」不屬於首版互動主流程；它在後續階段作為可分享、可列印或可匯出的唯讀研究快照。卷宗只能投影既有預測紀錄與證據，不得引入另一套計算語意。

## 使用者與目的

主要使用者是研究人員。系統協助他們：

- 快速找出跨期間訊號分歧、低信心、降級或不可預測的掛牌。
- 核對單一掛牌在不同預測期間的校準機率與資料支援。
- 將主要影響因素追溯至允許展示的特徵、文件片段與來源。
- 比較當時的正式預測與後續成熟標籤，不以事後重播覆寫歷史。
- 查明每筆結果所用的模型成品、特徵快照、資料集版本、服務指派與閘門政策版本。

介面不得提供自動下單、買賣指令、個人化投資建議或暗示主要影響因素具有因果關係。

## 導覽與路由契約

正式路由名稱可在 API 與前端規格階段調整，但必須保留下列資源關係：

| 路徑角色 | 建議路由 | 權威資源 |
|---|---|---|
| 研究入口 | `/research` | 股票池中各掛牌在共同資訊截止點的預測摘要 |
| 標的研究頁 | `/research/listings/{listing_id}` | 單一掛牌的不可變預測紀錄與證據投影 |
| 歷史預測 | `/research/listings/{listing_id}/predictions` | 按原始產生時間排序的正式預測紀錄 |
| 回測摘要 | `/research/model-families/{model_family_id}/backtests` | 模型評估報告及固定回測摺 |
| 後續卷宗 | `/research/predictions/{prediction_id}/report` | 單一預測紀錄的唯讀可分享快照 |

掛牌識別使用內部不可變 `listing_id`；股票代號只作有效期間內的顯示別名，不可作路由權威身分。

所有可分享狀態都應寫入 URL，包括資訊截止點、股票池、掛牌、市場、期間焦點、排序、篩選與細節頁籤。資料支援狀態是後端計算結果，不是讓使用者任意切換的正式篩選情境。

## 比較矩陣

### 必要內容

每列至少顯示：

- 掛牌代號、名稱、市場與股票池歸屬。
- 同一資訊截止點下 1／5／20 個交易日的上漲、盤整及下跌機率。
- 每個期間的信心分數。
- 資料支援狀態：完整、降級或不可用。
- 預測紀錄狀態：已產生或因硬性條件而阻斷。
- 服務中的模型成品簡短版本與預測產生時間。

### 必要操作

- 依市場、股票池、資料支援狀態、主導類別及信心範圍篩選。
- 依期間的類別機率、信心分數、資料異常或產生時間排序。
- 聚焦某一預測期間，但不可隱藏其餘兩個期間的存在。
- 點選掛牌進入標的研究頁，並保留入口的篩選與排序狀態供返回。

矩陣色彩只能輔助閱讀，所有狀態均須有文字及數值，不可單靠紅綠顏色表達。

## 標的研究頁

首屏必須並列呈現：

- 掛牌、所屬市場、資訊截止點與預測產生時間。
- 三個預測期間的完整機率分布、主導類別與信心分數。
- 資料支援狀態及各模態的完整度、時效與阻斷原因。
- 合成或正式資料的環境標示；非正式環境不得與生產結果混淆。

細節區依序提供：

1. **主要影響因素**：至少前五項正向及前五項負向貢獻，附特徵群組或文件證據指標，明示為模型歸因而非因果。
2. **來源證據**：來源角色、文件或資料版本、首次取得時間、允許的摘要／片段，以及來源政策限制。
3. **歷史預測**：保留當時的三類機率、模型成品與資料支援狀態；成熟後另接實現趨勢標籤，不修改原預測。
4. **滾動回測**：顯示相同模型家族及適用市場／期間的切片指標、校準、經濟回測與門檻結果。
5. **版本追溯**：預測紀錄、模型成品、特徵快照、資料集版本、服務指派、模型評估報告及閘門政策版本的識別碼與連結。

## 信心、缺資料與阻斷語意

- 信心分數只表示三類校準機率的集中程度；不得把它改稱準確率、資料品質或綜合信賴度。
- 資料支援狀態獨立顯示，不得因缺少可選模態而重新定義信心分數。
- 可選模態降級時，介面可展示既有機率，但必須在同一視野標出缺少的模態及影響範圍。
- 必要價量、身分、日曆、現行模型或版本譜系不足時，不得顯示虛構機率；介面顯示「不可預測」與機器可讀原因。
- 缺資料、來源授權禁止展示或證據被隔離時，介面不得以空字串或零值假裝有效結果。

## 證據與授權

- 只有來源政策版本允許展示的欄位、摘要或文件片段可送到研究介面。
- 原文不可展示時，以來源類型、標題、時間、政策狀態及允許的衍生結果代替。
- 介面查詢不直接讀取原始資料物件；它只讀取已通過政策與身分檢查的研究投影。
- 所有證據連結必須能回到產生預測時使用的不可變版本，不能默認跳到來源「最新」內容。

## 歷史預測與回測的區隔

- 歷史預測回答「當時正式產生了什麼」；追溯重播必須以不同狀態標示，不能混入正式序列。
- 滾動回測回答「固定模型與資料契約在歷史摺上如何表現」；不得將研究策略報酬展示成承諾報酬。
- 尚未成熟的預測顯示待觀測；缺少精確 realized session 時顯示不可評定，不得順延到下一個可用日期。

## 首版與延後範圍

### 生產導向 MVP

- 比較矩陣與標的研究頁。
- 股票搜尋、三期間焦點、篩選、排序及 URL 可分享狀態。
- 資料支援、主要影響因素、來源證據、版本追溯。
- 歷史預測與基本滾動回測檢視。
- 繁體中文介面、鍵盤操作、文字狀態及窄螢幕基本可用性。

### 延後

- 證據卷宗的列印、PDF、郵件或外部分享。
- 使用者自訂版面、儲存觀察清單與協作註記。
- 盤中即時更新、推播通知與交易整合。
- 複雜互動式情境分析或允許使用者改寫模型輸入。

## 驗收要點

1. 研究人員能從矩陣在兩次操作內進入任一掛牌的研究頁。
2. 每個可用預測同時顯示三類機率、信心分數與獨立資料支援狀態。
3. 不可預測狀態不顯示任何替代機率，並提供明確阻斷原因。
4. 每項主要影響因素可定位到具名特徵群組或允許展示的文件證據。
5. 任一歷史正式預測可追溯到模型成品、特徵快照、資料集版本及服務指派。
6. URL 重載後保留掛牌、資訊截止點、期間焦點、篩選、排序及細節頁籤。
7. 色彩移除後，使用者仍可由文字與數值理解所有趨勢及品質狀態。
8. 卷宗功能若實作，其內容與同一預測紀錄的研究頁完全一致，不另行計算機率或歸因。
