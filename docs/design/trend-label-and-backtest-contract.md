# 趨勢標籤與防洩漏回測契約

本文件固定台灣與美國個股 1／5／20 交易日三分類標籤，以及用這些標籤訓練、校準、選模與測試時必須遵守的時間點契約。目標不是讓三類樣本恰好等量，而是保留可解釋的經濟門檻，同時確保任何特徵、標籤、處理結果或模型選擇都沒有使用當時尚不可知的資料。分期股票池、baseline與正式歷史entry gate由[分階段架構交接契約](phased-architecture-and-spec-handoff.md)固定。

## 已驗證範圍與限制

一次性原型以 XTAI、XNYS 真實交易日曆及 2015-01-01 至 2025-12-31 的 10 檔台股、10 檔美股驗證門檻敏感度，共形成 157,610 個可用的 1／5／20 交易日聚合樣本。原型只保存聚合計數；Yahoo Finance Chart endpoint 的行情未保存且不是核准的正式來源。正式訓練與回測只能使用通過來源政策、涵蓋報告及時間點契約的資料集版本。

原型證明標籤分布具可學習性與契約情境能被明確表達，但沒有證明模型具有預測力，也沒有取代涵蓋完整股票池、退市標的與不同市場狀態的正式回測。

## 標籤定義

每個標籤對一個掛牌 `listing_id`、預測基準交易日 `t` 及預測期間 `h ∈ {1,5,20}` 負責。`t+h` 是同一交易場所 realized calendar 上第 `h` 個後續交易日，不是自然日偏移。

### 報酬與波動度

```text
future_return(t,h) = adjusted_close(t+h) / adjusted_close(t) - 1
sigma20(t) = sample_std(log(adjusted_close(s) / adjusted_close(s-1)))
             for the 20 realized sessions ending at t
threshold(t,h) = max(market_floor, 0.35 * sigma20(t) * sqrt(h))
```

`sigma20` 不年化，只使用截至 `t` 收盤已發生的 20 個報酬。價格必須由未調整行情、公司行動資料集版本與決定性調整規則生成的內部調整版本提供；供應商 adjusted close 只可交叉驗證。

市場下限預設為：

| 市場 | `market_floor` | 語意 |
| --- | ---: | --- |
| 台灣 | 0.60% | 成本與微小波動緩衝，不宣稱等於任何單一券商實際費率 |
| 美國 | 0.25% | 成本與微小波動緩衝，不宣稱等於任何單一券商實際費率 |

係數、下限、波動視窗及公式共同形成 `label_rule_version`；不得依某一測試季度的類別分布事後改動。

### 三分類與端點

| 條件 | 趨勢標籤 |
| --- | --- |
| `future_return > threshold` | `up` |
| `future_return < -threshold` | `down` |
| `-threshold <= future_return <= threshold` | `flat` |

缺少 `t`、精確 `t+h`、20 日波動視窗、realized calendar version 或調整版本時不產生三分類值，改以結構化狀態及原因保存。精確 `t+h` 缺價或停牌時使用 `invalid_endpoint`；不得偷偷順延到下一個有價格的交易日，否則不同掛牌會具有不同預測期間。

## 代表性分布結果

以下是預設規則的聚合比例，欄內順序為上漲／下跌／盤整：

| 市場 | 1 日 | 5 日 | 20 日 |
| --- | --- | --- | --- |
| 台灣 | 30.7%／29.3%／39.9% | 37.3%／31.7%／31.0% | 40.3%／29.4%／30.3% |
| 美國 | 36.8%／30.9%／32.3% | 41.4%／29.5%／29.1% | 47.1%／26.1%／26.8% |

三類均有足夠代表性樣本，不需要為了形式平衡改成事後分位數標籤。美股 20 日樣本的上漲偏斜是樣本期市場狀態的一部分；正式評估必須按市場、預測期間、年度／市場狀態、產業、規模與流動性切片報告，並與多數類別及簡單市場先驗比較。任何類別權重或重抽樣只作用於訓練 loss，不改寫真實標籤與測試分布。

## 時間點與時區契約

1. 原始時間先依來源的 `timezone_basis` 映射到正確交易場所 session，再保存 session ID 與 UTC 瞬間；不能先套用另一市場時區再按日期 join。
2. 原型反例把台股日線轉成 `America/New_York` 後再正規化日期，造成 21.85% 的 XTAI session mismatch，證明 `calendar_version`、`market_timezone` 與 session mapping 規則必須是資料血緣的一部分。
3. Production特徵快照的資訊截止點為各市場收盤後 90 分鐘。來源事實要求 `first_observed_at <= cutoff`；衍生特徵另要求 `feature_materialized_at <= feature_freeze`。
4. 平台建置前的正式歷史訓練／回測可以使用時間點契約中有效的 `archive_attested` 歷史可得性主張，但必須以 `historical_reconstruction` 模式選擇、在fold manifest列出主張ID，且不得冒充production觀測或預測。
5. 來源宣稱的 `published_at` 不能取代首次取得時間或archive證明。遲到、更正或撤回只影響後續平台觀測視圖；只有完整證明as-of版本與修訂語意的主張可建立新的正式歷史重建版本。
6. 預測建立時綁定當時的 projected calendar version；標籤按事後實際 realized calendar version 成熟。臨時休市延後目標交易日，但不改寫原預測。

## 標籤生命週期與血緣

每個候選標籤先有狀態而非預設值：

| 狀態 | 定義 | 是否可供訓練／評估 |
| --- | --- | --- |
| `pending` | 精確 `t+h` 尚未收盤，或必需資料仍未在允許延遲內到齊 | 否 |
| `mature` | 精確目標交易日已收盤，且有效調整價格與全部版本血緣已固定 | 是 |
| `invalid_endpoint` | 精確目標交易日沒有有效端點價格 | 否 |
| `invalid_history` | 基準價格或 20 日波動視窗不足 | 否 |
| `policy_blocked` | 來源政策不允許該訓練、保存或回測用途 | 否 |

不可變標籤版本至少保存：

- `listing_id`、`anchor_session_id`、`target_session_id`、`horizon_sessions`；
- `future_return`、`sigma20`、`threshold`、三分類值或無效原因；
- `label_rule_version`、`realized_calendar_version`、`adjustment_version`；
- 行情、公司行動及身分資料集版本與來源政策版本；
- 建立時間、程式／環境版本及輸入 manifest 雜湊。

公司行動或日曆後續修訂只建立新標籤版本。舊模型、回測與預測仍引用原版本，不以最新結果靜默覆寫。

## 滾動回測摺

每個市場獨立建立季度 walk-forward 回測摺：

| 區段 | 長度 | 用途 |
| --- | --- | --- |
| 訓練 | 測試季度之前的 7 年 | 擬合模型、前處理與訓練期統計 |
| 校準／驗證 | 接續 1 年 | 超參數／模型選擇、機率校準及閾值無關評估 |
| 測試隔離期 | 20 個 realized sessions | 隔離反覆使用的校準／驗證資料與一次性測試 |
| 測試 | 接續 1 季 | 模型與校準器凍結後只評估一次 |

正式升版報告至少涵蓋最新 8 個完整季度；不足時明示資料限制，不能用隨機切分補足。

### Purge 與 embargo

- 每個訓練或校準／驗證區段末端固定清除 20 個 anchor sessions，形成標籤清除區。這個值等於最大預測期間，即使本次只評估 1 日或 5 日也不縮短，以保持跨預測期間一致的資料血緣。
- 任一較早樣本若其標籤區間接觸或跨過下一區段首日，一律排除；固定 20 日清除區是保守實作，區間重疊檢查仍須存在。
- 模型選擇與機率校準完成後，保留 20 個 realized sessions 的測試隔離期，才開始計分測試 anchor。
- 測試資料、測試標籤、測試期類別比例及測試期成本結果不能回饋該摺的特徵選擇、超參數、校準或停止條件。
- 測試結果只有在標籤成熟後計算；下一個季度摺可依時間順序把已成熟舊資料納入自己的訓練視窗，但不得改寫前一摺結果。

所有標準化、缺值補值、類別權重、特徵篩選及 learned embedding 聚合器都只以該摺允許的訓練資料擬合。校準器只看校準／驗證區；測試區只套用已凍結轉換。

## 統計與經濟評估

每個市場與預測期間至少報告：

- macro-F1、balanced accuracy、每類 precision／recall 及 confusion matrix；
- multiclass log loss、Brier score、ECE 與可靠度圖；
- 相對多數類別、無資訊先驗及簡單價量基準的改善；
- 按季度與市場狀態的平均、最差值與穩定性，而非只報整期平均。

經濟診斷以預測上漲機率排序：台美都做 top 20% 多頭組合；美股另做多空市場中性診斷。至少報告 rank IC、IC information ratio、成本後報酬、換手、波動與最大回撤。它們是模型治理證據，不構成交易建議或交易執行功能。

每次經濟回測綁定交易成本情境版本。費用、稅負、買賣價差、滑價、換手公式、生效日期及市場差異都必須明示；不得以零成本作正式升版依據。實際升版數值門檻與現行模型比較規則由模型生命週期票券固定，本契約只規定不可省略的量測與時間邊界。

## 回測摺 manifest

每個回測摺發布不可變 manifest，至少包含：

- 市場、股票池版本、各區段實際 session ID 清單及時區；
- 每筆排除樣本的 `purged`、`embargoed`、`pending`、`invalid_endpoint`、`policy_blocked` 等原因；
- 特徵快照、標籤、日曆、調整、處理組合及來源政策版本；
- 每個歷史輸入的選擇模式、歷史可得性主張ID、證據等級及qualification版本；
- 模型、前處理器、校準器、超參數搜尋空間及亂數種子；
- 統計基準、交易成本情境、評估程式與環境版本；
- 產出雜湊、執行時間、程式 Git SHA 及涵蓋報告。

同一 manifest 與可用輸入必須能重建相同的樣本成員、標籤、模型 artifact 與評估結果；若數值函式庫只能保證容差內重現，容差及差異原因也要版本化。

## 必須通過的契約情境

- 台股與美股日線各自映射 XTAI／XNYS session，跨時區 join 不會移動 session date。
- 公告發布在截止點前、但首次取得或衍生處理完成在截止點後時，不會進入當日特徵快照。
- `archive_attested`資料可進正式歷史訓練／回測，但永遠不能被查詢成當時的production預測；只有`published_current_only`的最終值不能進正式回測。
- 拆股與股利不會在原始價格跳動處製造假趨勢；回測可重建當時使用的公司行動版本。
- 1／5／20 日標籤只使用精確 realized session；休市延後成熟，缺價不順延。
- 邊界前樣本的標籤區間不接觸後續區段，20 日標籤不會跨入校準或測試。
- 測試前有完整 20-session 隔離期，且任何測試結果都未用於該摺選模或校準。
- 逾時文件、retrospective annotation、後到更正及未成熟標籤不能進入歷史正式回測。
- 類別偏斜按時間與市場狀態報告，不以測試分位數重寫標籤。
- 經濟結果套用版本化成本及換手，零成本結果不能單獨通過升版。
- 任一指標都可回溯到回測摺、特徵、標籤、模型、校準器、成本情境及程式版本。
